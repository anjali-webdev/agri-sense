COMPLETE WORKFLOW: ESP32 → ThingSpeak → Streamlit
====================================================

This guide shows the complete data flow from sensors to dashboard.

PHASE 1: ThingSpeak Setup (10 minutes)
---------------------------------------
1. Create ThingSpeak account
   → Go to: https://thingspeak.com/
   → Sign up and verify email

2. Create channel
   → Channels > My Channels > New Channel
   → Name: AgriSense AI
   → Field 1: Soil Moisture
   → Field 2: Soil pH
   → Field 3: Temperature
   → Field 4: Humidity
   → Save Channel

3. Get API keys
   → Click "API Keys" tab
   → Copy Channel ID (e.g., 2785401)
   → Copy Write API Key (e.g., ABCD1234EFGH5678)
   → Copy Read API Keys (e.g., XYZ9876QWER5432)

✓ ThingSpeak ready!

PHASE 2: Configure Streamlit App (2 minutes)
---------------------------------------------
1. Copy environment file
   → Copy: .env.example
   → Paste as: .env

2. Edit .env file
   THINGSPEAK_CHANNEL_ID=2785401
   THINGSPEAK_READ_API_KEY=XYZ9876QWER5432
   THINGSPEAK_WRITE_API_KEY=ABCD1234EFGH5678
   ENABLE_DEMO_MODE=false

3. Save file

✓ App configured!

PHASE 3A: Test Without ESP32 (5 minutes - OPTIONAL)
----------------------------------------------------
If you don't have ESP32 yet, test with simulated data:

1. Run test sender:
   python send_test_data.py

2. Wait 2 minutes for data to appear

3. Verify on ThingSpeak:
   → Refresh your channel page
   → Check charts show data

4. Test Streamlit connection:
   python test_thingspeak.py

5. Run application:
   streamlit run app.py

✓ System working with test data!

PHASE 3B: Setup ESP32 Hardware (30 minutes)
--------------------------------------------
Hardware needed:
- ESP32 board
- DHT22 sensor
- Soil moisture sensor
- Soil pH sensor (with signal conditioning)
- Breadboard and wires
- USB cable

Connections:
DHT22:
  VCC  → 3.3V
  GND  → GND
  DATA → GPIO 4

Soil Moisture:
  VCC  → 3.3V
  GND  → GND
  AOUT → GPIO 34

Soil pH:
  ⚠️ MUST use voltage divider or 3.3V output module
  VCC  → 3.3V
  GND  → GND
  AOUT → GPIO 35 (with voltage divider if 5V output)

✓ Hardware connected!

PHASE 4: Upload ESP32 Firmware (15 minutes)
--------------------------------------------
1. Install Arduino IDE
   → Download from: arduino.cc

2. Add ESP32 board support
   → File > Preferences
   → Add URL: https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   → Tools > Board > Boards Manager
   → Install "esp32"

3. Install libraries
   → Sketch > Include Library > Manage Libraries
   → Install: "DHT sensor library" by Adafruit
   → Install: "Adafruit Unified Sensor"

4. Configure firmware
   → Open: firmware/esp32_agrisense/esp32_agrisense.ino
   → Copy config.example.h to config.h
   → Edit config.h:
     #define WIFI_SSID "YourWiFiName"
     #define WIFI_PASSWORD "YourWiFiPassword"
     #define THINGSPEAK_WRITE_API_KEY "ABCD1234EFGH5678"

5. For testing WITHOUT real sensors:
   → In esp32_agrisense.ino
   → Change: #define TEST_MODE false
   → To: #define TEST_MODE true
   → This sends simulated data

6. Upload firmware
   → Tools > Board > ESP32 Arduino > ESP32 Dev Module
   → Tools > Port > Select your COM port
   → Click Upload (→)
   → Wait for "Done uploading"

7. Monitor operation
   → Tools > Serial Monitor
   → Baud: 115200
   → Should see:
     ✓ Connected to Wi-Fi
     ✓ IP Address: 192.168.x.x
     --- Sensor Readings ---
     Uploading to ThingSpeak... ✓

✓ ESP32 sending data!

PHASE 5: Verify Data Flow (5 minutes)
--------------------------------------
1. Check ThingSpeak
   → Go to your channel
   → Refresh page
   → Charts should show data
   → New point every 60 seconds

2. Test Python connection
   python test_thingspeak.py
   
   Should show:
   ✓ Successfully connected to ThingSpeak
   ✓ Channel has data

3. Run Streamlit app
   streamlit run app.py
   
   Should show:
   - "LIVE IOT MODE" indicator
   - Real sensor readings
   - Historical charts
   - Crop recommendations

✓ Complete system working!

TROUBLESHOOTING
---------------
ESP32 won't connect:
→ Check WiFi name/password
→ Use 2.4GHz WiFi (not 5GHz)
→ Check Serial Monitor for errors

No data on ThingSpeak:
→ Check Write API Key
→ Verify ESP32 has internet
→ Wait 60 seconds between uploads (rate limit)

Streamlit shows "No data":
→ Check Channel ID and Read API Key in .env
→ Set ENABLE_DEMO_MODE=false
→ Restart: streamlit run app.py

Sensor readings wrong:
→ Calibrate sensors (see ESP32_SETUP.txt)
→ Check voltage levels (3.3V for ESP32)
→ Use TEST_MODE=true to verify communication first

DATA FLOW DIAGRAM
-----------------
Sensors → ESP32 → WiFi → ThingSpeak → Internet → Streamlit → Dashboard
  ↓         ↓              ↓              ↓           ↓
Read    Convert      Upload JSON     Store       Fetch      Display
        & Send       via HTTP        TimeSeries  via API    Charts

TIMING
------
- ESP32 reads sensors: Every 1 second
- ESP32 uploads to ThingSpeak: Every 60 seconds
- ThingSpeak stores: Immediate
- Streamlit fetches: Every 5 minutes (cached)
- User can force refresh: Click "Refresh Data" button
