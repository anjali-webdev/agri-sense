=========================

OPTION 1 - Automatic Configuration (EASIEST)
--------------------------------------------
Run this:
    setup_thingspeak.bat

It will ask for your Channel ID and create .env file automatically.


OPTION 2 - Manual Configuration
--------------------------------
1. Copy .env.example to .env
2. Open .env in Notepad
3. Replace these lines:

   THINGSPEAK_CHANNEL_ID=YOUR_CHANNEL_ID_HERE
   THINGSPEAK_READ_API_KEY=SH5CQT9IZ4ILD23P
   THINGSPEAK_WRITE_API_KEY=XXEPHX4HWZZN8IBV
   ENABLE_DEMO_MODE=false

4. Save and close


OPTION 3 - Use Python Script
-----------------------------
Run:
    python configure_env.py

Enter your Channel ID when asked.


AFTER CONFIGURATION
===================
Test connection:
    python test_thingspeak.py

Send test data:
    python send_test_data.py

Run application:
    streamlit run app.py
