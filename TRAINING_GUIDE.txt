MODEL TRAINING GUIDE
====================

The AgriSense AI system uses Machine Learning to recommend crops based on:
- Soil Moisture
- Soil pH
- Temperature  
- Humidity

OPTION 1: Train with Current Dataset (QUICK)
=============================================
Run:
    python scripts\train_model.py

Dataset: 110 samples, 22 crops (synthetic baseline)
Time: ~30 seconds
Accuracy: ~95% (on test data)

This is GOOD ENOUGH for demonstration and testing!

Output:
- models/crop_recommendation_model.joblib
- models/model_metadata.json
- reports/classification_report_[timestamp].txt


OPTION 2: Download Real Agricultural Data
==========================================
Run:
    python download_real_dataset.py

This downloads a real crop dataset from GitHub/Kaggle.
Transforms it for our 4 features.
Saves as: data/crop_dataset_real.csv

Then:
1. Backup current: copy data\crop_dataset.csv data\crop_dataset_backup.csv
2. Use new data: copy data\crop_dataset_real.csv data\crop_dataset.csv
3. Train: python scripts\train_model.py


OPTION 3: Add Your Own Data
============================
Edit: data/crop_dataset.csv

Required format:
soil_moisture,soil_ph,temperature,humidity,crop
45.2,6.5,25.3,65.5,Rice
32.1,7.2,28.5,55.2,Wheat
...

Guidelines:
-----------
1. Collect data from:
   - Agricultural research papers
   - Government databases
   - University extensions
   - Your own sensor measurements

2. Each row = one successful growing condition
   Example: Rice grew well with these conditions

3. Include multiple samples per crop:
   - Different seasons
   - Different locations
   - Different varieties

4. Balance dataset:
   - Try to have similar number of samples per crop
   - Minimum 20-30 samples per crop for good results

5. Valid ranges:
   - soil_moisture: 0-100 (%)
   - soil_ph: 0-14 (pH units)
   - temperature: -40 to 85 (°C)
   - humidity: 0-100 (%)


OPTION 4: Improve Current Dataset
==================================
You can add more samples to existing dataset:

1. Open: data/crop_dataset.csv
2. Add more rows with realistic values
3. Research optimal conditions for each crop
4. Save file
5. Run: python scripts\train_model.py


UNDERSTANDING TRAINING OUTPUT
==============================
When you run train_model.py, you'll see:

1. LOADING DATASET
   - Number of rows
   - Number of crops
   - Data validation results

2. PREPARING DATA
   - Features: 4 inputs
   - Target: crop names

3. SPLITTING DATA
   - 80% training
   - 20% testing

4. TRAINING MODELS
   - Random Forest accuracy
   - Decision Tree accuracy
   - Best model selected

5. CLASSIFICATION REPORT
   - Precision: How many predicted crops were correct
   - Recall: How many actual crops were found
   - F1-Score: Balance of precision and recall

6. CONFUSION MATRIX
   - Shows which crops get confused with each other

Example good results:
- Accuracy: > 80%
- Weighted F1: > 0.75
- Most crops have good precision/recall


IMPROVING MODEL ACCURACY
=========================
If accuracy is low (< 70%), try:

1. Add more data:
   - Minimum 200+ total samples
   - 20-30 samples per crop

2. Balance classes:
   - Equal samples for each crop
   - Or use class_weight='balanced'

3. Check data quality:
   - Remove duplicates
   - Fix invalid values
   - Verify measurements are realistic

4. Feature engineering:
   - Add soil type (if available)
   - Add season indicator
   - Add location/climate zone

5. Try different algorithms:
   - Edit scripts/train_model.py
   - Add XGBoost, SVM, etc.


RETRAINING WORKFLOW
===================
After collecting new data:

1. Add data to: data/crop_dataset.csv
2. Run: python scripts\train_model.py
3. Check accuracy in output
4. If good, model is auto-saved
5. Restart: streamlit run app.py
6. Test predictions with new data


EVALUATING MODEL IN APP
========================
After training, check in Streamlit:

1. Go to: Model Information page
2. Check:
   - Test Accuracy
   - Number of samples
   - Supported crops
   - Training date

3. Go to: Crop Recommendation page
4. Test with known good conditions
5. Verify recommendations make sense


AGRICULTURAL VALIDATION
========================
IMPORTANT: Technical accuracy ≠ Agricultural validity

Always:
✓ Consult agricultural experts
✓ Compare with regional guidelines
✓ Test recommendations in small plots

Machine learning predicts patterns in data.
