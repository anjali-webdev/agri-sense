THINGSPEAK SETUP GUIDE
======================

Step 1: Create ThingSpeak Account
----------------------------------
1. Go to https://thingspeak.com/
2. Click "Sign Up" (or "Get Started for Free")
3. Create account with email
4. Verify your email
5. Sign in to ThingSpeak

Step 2: Create a New Channel
-----------------------------
1. Click "Channels" > "My Channels"
2. Click "New Channel" button
3. Fill in channel details:
   
   Name: AgriSense AI Sensor Data
   Description: IoT sensor data for smart agriculture
   
   Field 1: Soil Moisture
   Field 2: Soil pH
   Field 3: Temperature
   Field 4: Humidity
   
4. Check "Make Public" (optional - for public sharing)
5. Click "Save Channel"

Step 3: Get Your API Keys
--------------------------
After creating the channel, you'll see:

1. Channel ID: (e.g., 2785401)
   - Located at top of channel page
   
2. API Keys tab:
   - Write API Key: (e.g., ABCD1234EFGH5678) - for ESP32 to send data
   - Read API Keys: (e.g., XYZ9876QWER5432) - for Streamlit to read data

Step 4: Configure Your Application
-----------------------------------
1. Open: .env.example
2. Copy to: .env
3. Edit .env and add your keys:

THINGSPEAK_CHANNEL_ID=YOUR_CHANNEL_ID
THINGSPEAK_READ_API_KEY=YOUR_READ_API_KEY
THINGSPEAK_WRITE_API_KEY=YOUR_WRITE_API_KEY
ENABLE_DEMO_MODE=false

Save the file.

Step 5: Test Channel
---------------------
1. Go to your channel page on ThingSpeak
2. Click "API Keys" tab
3. Scroll to "Test" section
4. Click "GET" next to "Read a Channel Feed"
5. You should see empty JSON response (no data yet)

Your ThingSpeak channel is now ready!
Next: Configure ESP32 firmware

Channel URL Format:
https://thingspeak.com/channels/YOUR_CHANNEL_ID

API Endpoints:
- Write: https://api.thingspeak.com/update?api_key=YOUR_WRITE_KEY&field1=VALUE
- Read: https://api.thingspeak.com/channels/YOUR_CHANNEL_ID/feeds.json?api_key=YOUR_READ_KEY
